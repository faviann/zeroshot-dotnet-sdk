# Migrating from 10.10.0 to 10.12.0

`10.12.0.1-preview.1` binds native Zeroshot 10.12.0. A client bound to 10.10.0 is
refused as `Mismatched`, so move your native pin and target image together with the SDK.
Native 10.12.0 adds local-folder runs and generic Git sources. The changes below can stop
existing code from compiling or change what it accepts.

## A run can have no source

A local-folder run has no repository snapshot, and native omits `source` for it. Every
contract that carries a run's source now allows its absence:

| Member | Before | After |
| --- | --- | --- |
| `RunRequest.Source`, `RunSubmission.Source` | `ResolvedSource` (required) | `Optional<ResolvedSource?>` |
| `RunStatusResult.Source`, `RunForceResult.Source`, `RunWatchEventNotification.Source` | `ResolvedSource` | `ResolvedSource?` |
| `HostedRunStatusResult.Source`, `HostedRunWatchEventNotification.Source` | `ResolvedSource` | `ResolvedSource?` |
| `RunDefinition.Source` | `ResolvedSource` | `ResolvedSource?` |

`Optional<T>` keeps an omitted source apart from an explicit `null`, as
`RunRequest.Environment` already does. A `ResolvedSource` still converts to it
implicitly, but a target-typed `new() { ... }` no longer does:

| Before | After |
| --- | --- |
| `Source = new() { Repository = ..., Branch = ..., Revision = ... }` | `Source = new ResolvedSource { Repository = ..., Branch = ..., Revision = ... }` |
| `StatusAsync(runId, request.Submission.Source)` | `StatusAsync(runId, request.Submission.Source.Value)` |
| `submission.Source == other.Source` | `submission.Source.Equals(other.Source)` |

A watch now compares every record with the first record's source, including its absence.
A record that gains or loses a source fails the watch as a protocol error.

## Source repository IDs and revisions accept more

A source with a `Remote` names any Git host, so `SourceRepositoryId` now accepts any ID of
1 to 255 UTF-8 bytes without control characters. The `owner/name` rule still applies to a
`ResolvedSource` without a remote, and the pinned schema checks it when the source is
serialized or decoded. `SourceRevisionId` accepts 40 or 64 lowercase hexadecimal
characters. Code that relied on `new SourceRepositoryId(...)` to refuse a value that is not
`owner/name`, for example a `MergePlanSource` repository, must check that itself.

## Dashboard template bindings are editor drafts

Native 10.12.0 templates can carry an agent draft with a blank model, such as
`{"kind":"agent","model":"","sessionScope":"node_instance"}`, which is not an admissible
binding. `DashboardTemplate.RuntimeBindings` is now an
`ImmutableDictionary<string, JsonElement>`:

| Before | After |
| --- | --- |
| `template.RuntimeBindings["deliver"] is GitDeliveryBinding` | `NativeJson.DeserializeUtf8<NodeRuntimeBinding>(JsonSerializer.SerializeToUtf8Bytes(template.RuntimeBindings["deliver"])) is GitDeliveryBinding` |
